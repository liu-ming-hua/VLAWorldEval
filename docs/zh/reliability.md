# 如何解释评估结果

[手册首页](README.md) / 评价边界 · [English](../en/reliability.md)

## 证据分别能说明什么

| 证据 | 可以支持 | 不能直接证明 |
| --- | --- | --- |
| 协议检查与执行成功 | 声明的接入路径能够运行，产物可审计 | 动力学正确或任务成功 |
| 真实动作回放 + 真实未来对照 | 该条已执行动作序列上的预测误差 | 未执行动作分支的物理正确性 |
| 冻结首帧基线 | 相比复制初始图像是否有所改善 | 可靠的动作因果响应 |
| 动作敏感性与消融 | 输出是否随条件变化 | 变化是否符合物理 |
| 域限定运动 / 交互诊断 | 校准域内的图像轨迹或事件 | 通用三维接触或机器人状态真值 |
| 同初始状态的真实动作分支执行 | 反事实动作跟随的验证基础 | 超出已测机器人 / 任务分布后的可靠性 |

真实轨迹确实包含动作及对应的实际未来，但不包含所有替代动作的物理未来。
随机 / 归零动作生成的视频，只有在替代动作也被实际执行后，才有对应分支真值。

## 报告规范

1. 固定源码、checkpoint、原生划分、相机 / 动作转换与推理参数。
2. 在查看输出前冻结选择；轨迹、窗口、长度与种子分开计数。
3. 真实未来与推理隔离；评分排除已有上下文与 padding 尾部。
4. 分别报告计划、可用、完成和评分数量以及缺失原因。
5. 按数据域、协议、长度和 checkpoint 分组，不跨不兼容条件排总榜。
6. 补充无动作基线与可得的真实动作分支，按 episode 估计不确定性。

## 指标定义

| 指标 | 方向 | 含义 |
| --- | --- | --- |
| MSE | ↓ | 对真实未来的像素误差，也与冻结首帧基线比较 |
| PSNR | ↑ | 对数图像重建指标，尺度与像素协议必须一致 |
| SSIM | ↑ | 图像结构相似度，不等于动作正确 |
| LPIPS | ↓ | 感知相似度；本实现使用解码后视频帧 |
| 运动 / 事件诊断 | 依具体协议 | 域校准的轨迹与事件，缺失标注不能算零误差 |

原始像素 MSE / PSNR / SSIM 与解码后视频 LPIPS 的处理链不同。
样本选择、checkpoint 和指标细节未完全对齐时，不得声称精确复现论文。
静态背景也可能取得较好图像分数，即使机器人动作错误。

## README 参考表的统计范围

| 模型 | 抽样与聚合边界 |
| --- | --- |
| Cosmos EEF FD | 400 条独立 DROID 轨迹，90 个长度 / 协议组；区间是组均值范围 |
| IRASim | 400 条独立 Language-Table 轨迹，26 个长度 / 协议组；区间是组均值范围 |
| DreamDojo | 官方发布的 100 个 GR1 in-lab 窗口，48 个纯未来帧 |
| IWS | 10 条 PushT validation 轨迹；展示 192 帧协议的三种子聚合 |
| Ctrl-World | 两条公开轨迹的 97 个重叠短窗口，每窗四个未来间隔 |
| WorldGym | 一条官方 Bridge test 轨迹、三种子，不是完整 OXE validation |

该表不是策略排名，也不声称完整复现所有论文测试集。
这些数值只是简洁的参考观测，新评价应使用冻结计划与版本化报告。
